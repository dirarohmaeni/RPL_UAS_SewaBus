# 🚍 Sistem Informasi Sewa Bus Berbasis Web

Sistem Informasi Sewa Bus adalah aplikasi berbasis web yang dirancang untuk membantu pengelolaan usaha penyewaan bus secara terkomputerisasi. Sistem ini memudahkan pengelolaan data bus, pelanggan, pemesanan, transaksi pengembalian, perhitungan denda, serta pembuatan laporan.

---

### 📌 Fitur Utama

- 🔐 Login & Autentikasi Admin

- 🚌 Manajemen Data Bus (Tambah, Edit, Hapus)

- 👤 Manajemen Data Pelanggan

- 📅 Pemesanan Bus

🔄 Pengembalian Bus

- 💰 Perhitungan Denda Otomatis

- 📊 Laporan Pemesanan

- 🖨 Cetak Laporan (Format Print)

---

### 🛠️ Teknologi yang Digunakan

- PHP (Native)

- MySQL

- HTML, CSS

- XAMPP (Apache & MySQL)

- Bootstrap / CSS Custom

---

### 🗄️ Struktur Database

Database terdiri dari beberapa tabel utama:

- users

- bus

- pelanggan

- pemesanan

Relasi antar tabel dirancang untuk mendukung proses penyewaan bus secara terintegrasi.

---

### ⚙️ Cara Menjalankan Project

1. Install XAMPP

2. Aktifkan Apache & MySQL

3. Pindahkan folder project ke:
   ```
   C:\xampp\htdocs\
4. Import database ke phpMyAdmin

5. Buka browser dan akses:
```
http://localhost/sewa_bus
```
